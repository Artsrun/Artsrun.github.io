AI stack in kaomoji

26 Sep 2026 · emoticon_string · stack v1

face · layer · stop — one act per noun

A screenshot sold twenty-one job titles as a career ladder. They are not a ladder. They are four rooms: what the model sees, how one agent repeats, how many agents are wired, and what the run is allowed to cost.

Kaomoji keeps the syntax. Each face is a speech act, not a badge. Read E as existence (what is already on the table), C as change (what the act moves), T as time (when it is allowed to stop). Mapping a face to an emoji is translation, not identity.

seerepeatwirerecallshapewatch

I · see

The window is finite. Packing it is the job.

Context engineering

(｀ー´)

Not the pretty sentence. The packing list: who is speaking, which files, which tools, which history, which ban. Tokens are seats. Unused seats still bill.

Ea finite window already thereCswap noise for load-bearing tokensTbefore the first generation

one thing: prompt is words. context is inventory.

Prompt optimization

(・∀・)↑

Keep two versions. Score them on the same set. Keep the winner. Poetry that cannot lose a bake-off is handwriting, not engineering.

Ea prompt that already runsCmutate, measure, keepTafter an eval set exists

one thing: no score, no upgrade — only taste.

II · repeat

One agent. A cycle. A stop that is not “looks done.”

Agentic AI

(｀Д´)

A goal plus tools plus the right to pick the next step. Chat answers. An agent acts, then looks at what the act did.

Ea goal that is not a questionCchoose an act in the worldTuntil a verifier says stop

one thing: if it cannot fail a check, it is still a chatbot.

Loop engineering

(￣ー￣)

Design the lap: plan → act → observe → evaluate → repeat. The prompt still exists. A machine now writes the next one. You design the stop, not every sentence.

Eone agent, one cycleCclose the loop with evidenceTwhen the bar is met — or the budget dies

one thing: a loop without a stop is a furnace.

Tool use

(｀ヘ´)

The model leaves the page: search, run code, hit an API, open a file. Words stay words until a tool moves something that is not text.

Ean action the model cannot fakeCcall it, read the resultTper step, not per essay

one thing: a tool is a verb with a receipt.

Function calling

(・∀・)

The contract under the verb: name, JSON arguments, typed result. The model fills a form. Your runtime runs it. Schema first. Vibes never.

Ea named function with a schemaCfill args → execute → returnTone call, one result

one thing: if the args cannot fail validation, the tool is a story.

MCP

(・_・)

Model Context Protocol — USB-C for tools. Discover search, files, calendar the same way instead of writing a new dialect per app. The model sees a catalog, not your private glue.

Ea standard socketCdiscover, then callTat connect, then per request

one thing: protocol is shared grammar. Adapter is still work.

Stateless MCP

(＾▽＾)

The 2026-07-28 spec drops the handshake and the session id. Each request carries version, identity, args. The server may forget you. Application state, if needed, becomes an explicit handle the model can see — not a sticky socket.

Ea self-describing requestCmove session out of the transportTevery call stands alone

one thing: stateless protocol ≠ stateless product. Handles are state you admit.

III · wire

One loop is a node with an edge back to itself. A team is a graph.

Multi-agent systems

(ﾉ´ヮ´)ﾉ*: ・゜

Specialists: researcher, coder, critic. Split, hand off, disagree, merge. One brain stalls on role collision. A crew routes.

Emore than one mouth with a jobChandoff with shared stateTwhen the join condition holds

one thing: extra agents without a join are a committee.

Graph engineering

(・∀・)

Nodes, edges, typed state. Who may speak to whom, where it branches, what a veto looks like. The agent still chooses inside a node. You choose the legal paths.

Emany loops that must not collideCdraw topology + routingTper transition, not per monologue

one thing: graph does not replace loop. It composes loops.

AI gateways

( ⌒▽⌒)⊃━☆

One door: auth, route, rate-limit, log, swap the vendor. Apps speak the gateway. Twelve model APIs stay behind the wall.

Emany backends, one contractCroute and record the callTevery request

one thing: a gateway is a customs desk, not a brain.

IV · recall

Look things up. Do not stuff a diary into every window.

Vector DBs

(=^..ω..^=)

Vector database: meaning as numbers. Nearby in space ≈ nearby in sense. Fast fuzzy recall. Not a ledger. Not a source of truth. An index of resemblance.

Eembeddings already storedCnearest-neighbor fetchTat query time

one thing: similar ≠ true. Rank is a hint.

RAG 2.0

(・_・?)

RAG (Retrieval-Augmented Generation) v1 embeds the question, dumps top chunks, hopes. 2.0 treats retrieval as a tool: plan the ask, fetch, check, fetch again. Search is no longer a pipe. It is a verb inside the loop.

Ea corpus the model does not containCretrieve until grounded enoughTwhen evidence covers the claim

one thing: one-shot retrieve is a search box wearing a lab coat.

Memory layers

(￣ω￣)

Scratchpad this turn. Session this sitting. Long-term across sittings. Compress or offload before the window rots. A diary pasted into every prompt is not memory. It is flood.

Efacts that outlive one replyCwrite / compress / recall by layerTacross turns, not inside one shot

one thing: layer or drown.

V · shape

Change the weights only when the window and the tools are not enough.

Fine-tuning

(；一_一)

Bake a narrow habit into the weights: tone, format, a small domain. Expensive to start, cheap to serve later. The wrong fix if retrieval already holds the facts.

Ea base model + labeled examplesCnudge the weightsToffline, before serving

one thing: tune for manner. Retrieve for matter.

Synthetic data

(つ✧ω✧)つ

Structured fakes when the real set is scarce, private, or dull. Useful for drills and evals. Garbage that rhymes with itself trains a confident parrot.

Ea generator + a validity checkCmint examples that pass the checkTbefore train / before eval

one thing: fake data still needs a real test.

Distillation

( ˙꒳˙ )

A large model teaches a small one. Same answers, thinner body. You copy the teacher’s outputs, not its size. Rent drops. Ceiling drops with it — measure how far.

Ea teacher that already knows the jobCtrain the student on teacher tracesToffline; serve the student

one thing: smaller is a budget. Not a miracle.

VI · watch

If you cannot see it, score it, fence it, or pay for it — you do not run it.

Evaluation frameworks

(｀ー´)✓

A suite: correctness, refusal, tool success, drift, cost. The same suite for every change. Taste is allowed after the numbers.

Etasks with known good / known badCscore the run, keep the logTon every candidate, not at launch day

one thing: unevaluated “better” is a mood.

Guardrails

(╬ Ò﹏Ó)

Hard fences: secrets stay in, jailbreaks stay out, spend has a ceiling, tools have a whitelist. Policy before personality. A witty agent with no fence is an incident waiting for a tenant code.

Erules that do not negotiateCblock, redact, escalateTbefore the act lands

one thing: a rail is a veto, not a vibe.

Observability

(눈_눈)

Traces, tokens, tool names, latency, the reason a loop stopped. If you cannot replay the face that flipped the table, you cannot repair the walk.

Ea run that already happenedCrecord enough to replayTduring the run, not in the postmortem wish

one thing: logs are the archive. Relapse is invisible without one.

Cost optimization

(￣▽￣)ゞ $

Smaller model. Cache. Shorter context. Fewer loops. Batch. Distill. Intelligence is rent. A graph that retries without a budget is a luxury furnace.

Ea bill that compounds per token and per lapCcut waste that eval still acceptsTevery day the meter runs

one thing: the cheapest correct loop wins.

How to walk the list

Start at see. If the window is wrong, no loop will save you. Then give one agent a lap and a stop. Only then draw a graph. Recall before you fine-tune. Watch before you scale. Cost is not a last slide — it is the T on every card.

The screenshot was a wardrobe. This page is a path: open the window, walk a loop, wire a crew, remember on purpose, change weights last, keep the lights on.
